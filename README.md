# Haunted House MOD 👻

Minecraft 26.3 / Fabric / Java 25

探索中に不気味なお化け屋敷を見つけ、招待状で屋敷を呼び出し、幽霊から逃げるホラー探索MODです。

## 実装状況
- [x] Fabric MODプロジェクトの基本構成
- [x] 「お化け屋敷の招待状」アイテム登録
- [x] 招待状をブロックに使用して小さなお化け屋敷を生成
- [x] 屋敷生成時に敵対するVex（幽霊の試作）を召喚
- [x] 探索したチャンクで低確率（約128チャンクに1回）のお化け屋敷自然生成
- [x] 自然生成した屋敷にも幽霊の試作を配置
- [x] 日本語・英語のアイテム名と幽霊名
- [x] 招待状にエコーシャードの見た目を使用
- [x] アメジストの欠片4個と紙1枚で招待状をクラフト可能
- [ ] 専用の幽霊エンティティ・専用モデルとテクスチャ
- [ ] オリジナル効果音・専用テクスチャ
- [ ] ゲーム内テスト

## 遊び方
- 招待状を入手するには、ゲーム内で `/give @s haunted_house:invitation` を実行します。
- 平らな場所のブロックに向かって招待状を右クリックすると、屋敷と幽霊が出現します。
- 新しいチャンクを探索すると、低確率で屋敷が自然生成されます。

## 注意
幽霊は現時点ではバニラのVexを使った試作です。専用モデル・専用AIはまだありません。
ビルド成功とゲーム内動作確認は別です。実際のMinecraftで確認できた機能だけを完成扱いにします。

## 開発環境
- Minecraft 26.3
- Fabric Loader 0.20.1
- Fabric API 0.166.0+26.3
- Java 25
- Gradle 9.8.2
- Fabric Loom 1.19.4

## ビルド
Java 25 と Gradle 9.8.2 以降を用意し、ルートで `gradle build` を実行します。成果物は `build/libs/` に出力されます。
