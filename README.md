# Haunted House MOD 👻

Minecraft 26.3 / Fabric / Java 25

探索中に不気味なお化け屋敷を見つけ、招待状で屋敷を呼び出し、幽霊から逃げるホラー探索MODです。

- [ ] 幽霊モンスター（追跡AI・攻撃）
- [ ] ワールド探索中の自然生成
- [ ] 日本語・英語の翻訳とテクスチャ

## 開発環境
- Minecraft 26.3
- Fabric Loader
- Java 25
- Gradle 9.8.2
- Fabric Loom 1.19.4

## ビルド
Java 25 と Gradle 9.8.2 以降を用意し、ルートで `gradle build` を実行します。成果物は `build/libs/` に出力されます。
